# 2.0 验证记录（历史）

日期：2026-10-31。

环境：小米 10S / `thyme`，Android 11（API 30），MIUI 12.5.8，Magisk 28.1。

## 已验证

- APK 覆盖安装与沿用原签名。
- APK 内置模块 ZIP 与独立构建模块 ZIP 的校验值一致。
- 从 APK 安装内置模块并在线升级现有模块。
- 普通发送恢复 `A2dpService`、AVRCP Target 与 Audio Source UUID 广播。
- 接收模式的 A2DP Sink、AVRCP Controller、发送端连接及活动音轨。
- 当前模式与开机默认独立保存。
- 开机默认接收、开机默认发送，以及分别记住两种上次模式的脚本分支。
- 蓝牙关闭时切换角色仍保持关闭，重新开启后角色正确。
- 最终验证中切换不再增加系统记录的蓝牙进程重启次数。
- 模块及应用未包含 USB／ADB 配置写入。
- Shell 语法检查与 APK 签名验证。

默认模式分支通过执行模块的 `post-fs-data.sh` 和 `service.sh` 验证；这轮默认分支验证没有再次整机重启。

## 限制

普通发送验证了服务、广播及管理接口恢复，未逐一验证每种耳机。接收模式已观察到发送端播放和扬声器输出路由，未测量端到端延迟，也未进行长时间压力测试。

其他机型、其他 Android 版本、其他 root 方案没有列入 2.0 的支持范围。
